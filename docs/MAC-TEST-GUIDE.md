# Mac 本地试用（preview.6）

适用 macOS 13 或以上、Apple Silicon（arm64）。程序内置 Electron、SQLite、浏览器与 MCP，无需自行安装 Node、Docker、PostgreSQL 或 Redis。当前安装包未使用 Developer ID 签名及公证，其他电脑的 Gatekeeper/安装升级仍未验收；不要关闭系统安全设置来绕过失败，保留系统提示用于定位。

1. 打开 DMG，将 Social Lead Desktop 拖入 Applications，再从应用程序打开。首次初始化不创建工作台账号，也不启动平台业务。
2. 先测试本地操作：配置管理中创建多组关键词/匹配方案/模板，在自动化任务中选择关键词组，调整该组账号、笔记数及匹配方案。有效设置自动保存；切换页面和重启后应保留。没有账号时可以先测试关键词和笔记数。
3. 数据保存在 `~/Library/Application Support/SocialLeadDesktop`，与原项目服务版的数据分开。升级本测试 App 会继续使用这个目录。已有桌面试用数据时，先在“数据与恢复”创建业务备份；不要在运行时手动拷贝 SQLite 主文件。
4. 需要使用小红书时，在账号中心明确授权扫码。开始前先结束旧工作台同一账号的任务，避免两套执行器争用账号。登录凭据留在本机系统保护区；本地资格检查只检查已保存记录，实际操作还会核验平台身份。
5. 采集仍需预览范围并确认；每批或本轮剩余审核需明确付费授权。自动联系规则必须先授权，再在本轮采集时明确选用。保存偏好、查看记录和诊断不会调用模型或发送。规则不会因为上次选用而在新轮次自动勾选。
6. 消息出现“缺少可靠入站身份，只可查看”时，不能通过改配置解除。导入旧消息不产生回复资格；需要原账号重新登录并由受管收件流程核验对应入站证据。
7. UNKNOWN 保持额度和去重；在待处理页核对可靠证据，不能按普通失败重试。模型 UNKNOWN 与平台 UNKNOWN 分开处理。

旧数据迁入先生成副本、展示数量和限制，再经确认切换；不会覆盖源数据库或恢复旧授权任务。被旧系统覆盖掉的逐轮原文无法恢复，不会伪造。业务备份不含 Cookie、Key 或来源访问凭据，换机器需重新配置。

已完成合成界面与包内离线验证。真实平台、付费模型、跨机器安装/升级和 Windows 真机仍未验收；具体页面差异在 DESKTOP-PAGE-PARITY.md。模型运行页没有供应商实际账单/Token 数据，显示的请求占用不等于实际费用。
