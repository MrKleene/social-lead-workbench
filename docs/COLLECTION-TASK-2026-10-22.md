# 采集任务页简化 · 2026-10-22

关联 REQ-002/007/031/033；基于 B 引力场前端 44ab2e5。仅调整前端，未修改后端、数据库、凭据、启动器或平台授权。

## 使用路径

首页「自动化采集」，或 `/work?module=runs`。待命页仅保留标题、一行已保存配置摘要、开始/停止、采集结果与进度消息。参数统一进入「采集设置」；只有多组配置时显示组选择，常用参数先显示，技术范围和模拟选项折叠。新增/编辑沿用已有配置 API，关键词、规则和默认帖子上限保存后复用。临时本轮帖子数/模拟页数仅在当前页面保留，关闭抽屉或模块返回不丢失；刷新页面仍使用保存的默认值。

缺关键词只提示配置，缺可用账号/设备引导原账号中心，LLM/Key 不是基础采集门槛。真实模式点击「开始采集」后，显示一次紧凑账号、设备和单轮只读授权确认；未勾选不能提交。模拟模式仍明确标示。没有新增确认或变更原后端保护。

## 进度与结果

消息来自现有任务、统计及原文归档 API，按任务和事件 ID 去重，数量就地更新，保留已返回帖子。没有假打字、生成式文案或推测中的逐篇采集游标。查看历史或向上阅读不强制滚到底部，可点击「回到最新进度」。完成后主操作突出「查看采集结果」。部分、停止和失败状态及原因保持显著；完整有限批次不等于完整评论覆盖。详细统计、最近任务历史与手动刷新在折叠详情内。

现有 API 的自动状态刷新有时限，归档列表仅读最近 20 个帖子版本；未新增后端实时日志、精准补采或无限轮次能力。实时一级评论/回复拆分仅在后端返回有效统计时显示；没有数据不伪造数值。长期持续采集和完整覆盖仍待独立验收。
