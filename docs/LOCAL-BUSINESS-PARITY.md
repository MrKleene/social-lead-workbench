# 本地业务迁移核对（2026-11-06）

Electron/SQLite v9 隔离分支；详情见 [桌面实现与证据](DESKTOP-LOCAL.md)。以下为代码与合成验收范围，真实平台和 Windows 仍未验收。

| 行为 | 已接入并合成验证 | 仍需验证或无法自动恢复 |
| --- | --- | --- |
| 采集 | 原 boundedRead/根回复计数/成员屏障；独立轮次原文；分块检查点；单帖重读；跨轮复制后重新验证锚点；实际 XhsMcpAdapter 已注册 | 平台可见性/覆盖、真实断点恢复；旧系统覆盖掉的原文无法重建 |
| 审核 | 原 prepareOutbound/validateQwenEvidence；整帖预算和证据；持久提交意图；独立完整历史原文使用当前政策/模型、逐批新授权 | 真实付费接口未调用；不重放模型 UNKNOWN，不赋予独立审核自动联系资格 |
| 自动联系 | 多规则草稿、精确授权、采集前冻结、整轮完整后幂等编排、取消与提交前重验；额度/禁发/身份保护 | 真实平台执行能力与策略效果 |
| 人工发送 | 通过审核后人工预览/授权；独立审核保留原文证明；评论精确目标预检；私信可靠入站锚点；最多一次提交；原严格回执/日志/停止证明 | 实际平台发送未验收 |
| UNKNOWN | 两次独立停止的只读会话、严格账号/对象/内容/消息证据；取消/冲突保持未知；确认后仍占额度且暂停需再核对 | 缺身份绑定/多条冲突旧记录仍存档并阻塞；模型 UNKNOWN 不能用平台证据处理 |
| 收件 | 有界十五分钟授权；账号/代次/租约；历史与新消息；去重；先停止后让出发送，同一截止时间续收；界面状态/取消 | 自然新消息及时性、长时真实稳定性 |
| 历史迁移 | 业务白名单完整归档；可靠采集/审核映射；精确旧 UNKNOWN 建只读核对记录；配置、账号、额度、限制、收件及已回复标记；副本预览切换、原库保留 | 实际数据库导出/迁移未执行；来源模糊不伪造逐轮历史；不能续跑旧授权任务 |
| Mac 桌面 | 固定 IPC、免工作台登录、系统密文；实际浏览器/MCP/监督器随包；离线包自检/浏览器链路、合成 GUI | 无 Developer ID/公证、Gatekeeper/升级/其他机器或 Intel Mac 验收 |
| Windows 桌面 | 固定 ZIP 静态校验、PE x64 MCP 交叉编译；ACL/DPAPI/Job/日志源代码；原生测试后才可 NSIS 打包 | 无 Windows 真机；helper 编译、浏览器运行、系统凭据和安装升级均未验收，尚无 Windows 安装包 |

LocalQueue 授权不向 renderer 暴露。自动联系必须持有本轮开始前冻结且仍有效的规则来源；人工通过不自动生成发送。重新登录不解除风险，平台读取核对也不清除账号限制、历史去重或占用额度。来源令牌只进系统密文库。

测试证据：161 项本地测试、22 项桌面 IPC/原生/SDK 测试；`desktop:build` 类型检查和 Vite；实际 Mac Electron 合成界面含多关键词/目标/规则、历史原文与独立审核、旧 UNKNOWN 登录限制、备份、迁移/重启和窄屏。所有测试禁止真实平台或付费调用。打包结果及离线组件证据在 `.local/desktop-qa`。

应用运行不依赖原项目 node_modules、Prisma、PostgreSQL 或 Redis。纯规则、原模型和平台适配器分别构建为固定包并记录源摘要；许可随应用提供。正式发布检查仍阻止发布，不能以合成测试代替上述剩余验收。
