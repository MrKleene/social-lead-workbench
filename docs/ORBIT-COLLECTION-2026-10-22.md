关联 REQ-002/003/007/031/033。基于 `aeab508`，用户明确选择新版 B 引力场并批准写入正式前端；不是旧 64181 流水线方案。仅修改前端、回归脚本及说明，没有后端、schema、数据库、凭据或启动器变更。

## 使用路径

- `/work`：中央唯一突出按钮“自动化采集”，关键词、账号和采集结果为次级卫星。顶部胶囊和 Dock 保留设置、评论审核、销售、话术、账号和提醒。
- 点击主按钮进入 `/work?module=runs`，只读检查本地保存状态。缺关键词展示现有编辑器；缺有效账号/设备只引导已有账号中心。保存关键词不启动任务，账号核验也不会因页面打开自动执行。
- 真实读取仍须选择账号并确认单次授权、范围。保留模式、设备、并发、退避和服务端校验。模型与 Key 不是基础采集门槛；没有新增自动运行、定时或换号。
- `/work?module=archive`：独立原文库，无需进入 CRM 或配置模型。按配置、任务归属、当前页文本、帖子和一级评论/回复筛选；展开原文、父评论、来源与既有评估证据。未分析显示“无评分”。语义分析与 LLM 开关单独展开，沿用现有批次预览与费用确认。
- 查看/折叠模块保留筛选、选择和滚动；主动作聚焦后进入标题，返回恢复主按钮焦点。销售权限不获得采集配置或原文管理权限。

## 可见状态与边界

运行区显示真实任务状态、已提交的计数、已归档帖子和停止原因。PARTIAL/UNKNOWN 不表示全部评论完成。现有 API 没有逐步骤/当前处理帖子游标，页面明确说明，不绘制虚构实时阶段。

原文接口每页 50 条评论、最近 20 个帖子版本；搜索与帖子筛选限定当前窗口。任务归属仅有首次/最近观察 ID，不能还原中间每轮完整快照；界面已说明。缺原文的旧记录不能重建，不自动补采。暂停结束当前有限窗口并保留已存原文，不冒充精准断点续采。

真实评论/私信、全评论覆盖、多账号持续采集、实际 LLM 效果与付费联调没有因本轮 UI 验收而升级为可用。

## 动效与来源

原创 WebGL 引力光球、轨道和稀疏粒子，复用已有 React Bits Dock/SpotlightCard（许可保留在 `apps/web/src/vendor/react-bits/`）。没有使用 Hydra、第三方品牌或其资产。对应入口的连续展开可打断；业务文字保持 DOM 阅读面板。保留暂停、系统减少动效、隐藏页暂停、DPR 上限 1.25 和 WebGL 失败静态降级。无帧率或低端 GPU 性能承诺。
