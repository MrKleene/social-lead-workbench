## 首要发现：双重聚焦已明确复现

页面：正式登录页。控件：登录邮箱、密码。鼠标点击及 Tab 键聚焦都复现，稳定动画结束后的 computed style：

```css
border: 1px solid rgb(217, 227, 233);
outline: 2px solid rgb(18, 133, 111);
outline-offset: 3px;
/* box-shadow 中另有独立3px蓝紫色ring */
box-shadow: ...,
  oklab(0.641587 0.000999391 -0.115601 / 0.5) 0 0 0 3px,
  rgba(0,0,0,.05) 0 1px 2px 0;
border-radius: 8px;
```

原有1px输入边框之外，3px蓝紫box-shadow和偏移3px的2px海松绿outline同时可见。这里不是错误态，也不是浏览器自动填充：未输入任何字符，两个输入框为空。鼠标点击文本输入框也匹配 :focus-visible，这是浏览器对文本编辑控件的正常判定，不应错误依赖「只鼠标点击就不会focus-visible」解决。

复现：打开当前未登录工作台 → 点击邮箱 → 等过渡稳定；再按Tab到密码。截图02为鼠标，03为键盘；01是操作前现状（密码已聚焦）。建议工程集中统一Input/Textarea/Select与全局focus-visible的责任，保留清晰键盘焦点，避免逐页隐藏所有outline。双圈并非任何情形都违反规范，但本例混用两种焦点颜色且视觉重复，与统一海松绿设计不一致。
