## 可复现问题

### 1. 单帖检查复选框与说明分离 — P2，建议修复

步骤：采集信息 → 单帖检查。两个复选框“验证评论翻页与回复”“确认本次只读检查”均在宽行中央，说明文字落到下一行左侧。不是输入聚焦错误，但破坏授权选项的视觉关联。

现场 DOM：两者父级均 `label.login-consent`，`display:grid; gap:8px`；input 的实际矩形宽 **511px**、高 13px、`display:block; margin:5px 0 0`。原生方框画在整行中间。第二行与多行说明更分散。截图 [36](36-diagnostic-checkbox-issue.jpg)、[16](16-diagnostic-drawer.jpg)。精确值保存在 checks.json 的 diagnostic-checkbox-layout。

对照：重新读取确认的同意行正常，方框紧邻文字，见 [37](37-reread-confirm.jpg)。线索“仅未分配”及模型同意项也未见此错位。建议局部修复 `.login-consent` 的列布局/checkbox尺寸，避免全局表单宽度影响；不能以去掉焦点遮掩。

### 2. 配置已选复选框仍为原生蓝色 — P3，主题一致性

步骤：搜索与模型设置 → 教培“编辑”→ 下部“保存后启用”。该既有勾选状态显示蓝色，和海松绿焦点/操作不同；本轮没有切换其值。见 [29](29-config-lower.jpg)。这是主题一致性问题，不单凭颜色判定可访问性不合规。建议统一 checkbox accent-color，保留选中及强制色可辨性。

### 3. 模型设置排版与其他表单不同 — P3，可读性风险

展开“模型设置 · 仅管理员”，模型/地域标签紧挨短选择器，而其他字段标签在整行输入上方；价格、预算、用途说明是长串密集小字。见 [30](30-model-settings.jpg)、[31](31-model-lower.jpg)。没有重叠或页面横向溢出，但扫读明显弱于账号、话术、关键词表单。建议统一标签对齐与字段栅格，把长说明分段。未作全部文字对比度测量，不能据截图断言 WCAG 失败。

### 4. 可见业务说明存在旧状态矛盾 — 内容问题，另交工程核对

任务中心写“平台采集、自动评论和私信尚未启用”（34）；平台能力写“小红书未接入／本项目未连接”“虚构账号占位”（35）；而正式采集信息可查看已保存真实帖子、任务记录且账号中心显示已保留本机会话引用。搜索配置下部还有“当前MCP不支持游标续读，仅取返回窗口”（29），重新读取表单却明确“分块保存，优先恢复未完成的读取”（37）。本轮不测试后台能力，不替工程改写事实，但这些当前文案不能同时代表同一能力状态，应区分历史说明、当前支持和当前账号是否已核验。

旧封面缺失另记数据/媒体可用性：9卡片中较新的3篇封面正常，6篇显示“封面暂不可用”。占位布局稳定，不能称全部媒体加载通过，也未请求原站来验证失效原因。

## 行为与样式实测

- 本轮 viewport 1920×827。所有截图对应页面 document.scrollWidth 为1905或1920，不超过1920；长页正常纵向滚动，抽屉右侧关闭按钮没有遮挡标题。
- 普通输入/textarea/select：`outline:2px solid rgb(13,115,95); outline-offset:-1px; box-shadow:none`。复合评论/线索搜索 input 自身 outline:none，父级同色2px，未双叠。
- 按钮键盘：外侧同色2px，offset2px；无旧紫色阴影。滚动区焦点内侧offset-2px。
- 评论列表 PageDown 后 scrollTop283.5，clientHeight303，scrollHeight8253；页面高度仍827。长正文外层 clientHeight469、scrollHeight557，滚到88即末尾，右栏不随动。
- 跨页上下文查找的是本帖已保存内容；已证回复过滤保留，输入搜索清空后恢复全部。上一/下一页未请求原站。
- 本轮未逐项重新量化色对、字号或所有触控目标；不能以主题看起来一致当成合规认证。
