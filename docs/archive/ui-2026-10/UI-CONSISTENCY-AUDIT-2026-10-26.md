## 结论与证据边界

输入框双重高亮已复现并从源头修复。它是本项目的视觉一致性问题；“所有双圈都违反 UI/WCAG”不是正确结论。采用一套清楚的焦点指示，同时保留错误边界、键盘操作和强制色模式。

- **正式现场 R**：先复现登录页绿色 outline + 蓝紫 ring。随后用户恢复登录，独立浏览器任务实际覆盖 **12 个受保护主页面/模块（9 个工作台视图 + 3 个独立路由）**，有31张截图。追加修复后再次只读核对单帖检查、配置、模型设置、平台能力及人工任务，有6张新截图。未退出或替换用户会话。
- **隔离渲染 I**：新浏览器上下文、临时静态端口、合成响应，拦截外网和业务请求。全站新增回归覆盖 108 次页面/尺寸渲染、288 个输入焦点检查、40 个状态断言；不是 108 个不同页面。视口宽度 320、390、768、1440px；其他既有测试另含 2048px、低高度 600px。
- **代码审查 C**：条件分支、未安全构造的状态、未挂载组件仅算源码覆盖。不能把 import 可达、CSS 规则存在或测试总数等同于实测。
- **未测 U**：无真实样本的线索详情、审核/联系/销售/任务行，真实扫码/设备恢复、真实外发、所有浏览器/操作系统组合、读屏器全流程和全站 WCAG 认证。主页面空态通过不代表其有数据详情通过。

完整可核查材料：[截图与断言索引](evidence/ui-consistency-2026-10-26/INDEX.md)、[源码样式与组件清单](evidence/ui-consistency-2026-10-26/source-inventory.json)、[正式现场报告](evidence/ui-consistency-2026-10-26/production-before/AUDIT.md)。附件 `libfile_b8e23787b7fc81918afebb886f64ac68` 已按 Library 流程尝试物化，下载失败，未读取附件像素；结论使用现场与隔离证据，未猜测附件。

| 抽屉长标题与关闭按钮易重叠，正文滚动需要明确尺寸 | header 未为绝对定位关闭按钮预留空间，flex 子滚动区 min-height:auto | header 右侧预留64px、关闭按钮32px、sheet max-height:100dvh、detail-scroll min-height:0 | model-confirm、lead-sheet、配置抽屉；长正文测试 |

修复没有把所有 outline 隐藏。普通按钮/链接使用与填充色分离的外侧2px焦点；阅读滚动区用内侧线避免被裁切。文本框错误态使用 destructive 线，错误消息仍由既有业务校验提供。单个 aria-invalid 模拟仅验证样式，不冒充完整校验流程。

| 类别 | 当前约定/观察 | 本次结论 |
