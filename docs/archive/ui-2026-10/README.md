## 还有什么值得读

配色和截图都过期了，但有两件事仍然有效，已经提炼进现行规范：

1. **焦点双圈根因**：全局 `outline` 与组件 `focus-visible:ring` 同时生效，
   产生两圈颜色不同的焦点。见现行 DESIGN.md 第 7 章 Don't。
2. **`[data-slot]` 全量覆写的代价**：堆出 155KB 死规则后被整体删除。
   见 `AGENTS.md` 第 2 章。

除此之外的对比度数值（5.7777:1 等）是按旧配色算的，**不要引用**。
