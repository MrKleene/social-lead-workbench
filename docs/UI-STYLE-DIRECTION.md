## 一、现在的风格：三个东西叠在一起，没有一个是"成品"

### 1. 表面层：未改造的 shadcn-admin 模板

登录页实测（`docs/evidence/ui-style-audit-2026-11-09/login-desktop-1440.png`，1440×900，DPR 2）：

| 项 | 实测值 |
|---|---|
| 页面底色 | `oklch(1 0 0)` = 纯白，无层次 |
| 正文色 | `oklch(0.129 0.042 264.695)` ≈ `#020618` |
| 主色 | `oklch(0.208 0.042 265.755)` ≈ `#0f172b` |
| 圆角 | `--radius: 0.625rem`，按钮/输入 8px |
| 字体 | Inter → PingFang SC → …（`font-inter`） |
| 标题 | 20px / 500 |
| 标签 | 14px |
| 输入框 | 高 36px |

结构是上游 `satnaing/shadcn-admin` 的 sign-in 模板：白底 + 居中单卡 + 近黑主按钮。
证据不止配色——**上游的英文和 demo 页面还在**：

- 密码框旁的 `Show password`（中文界面里的英文）——**已改为「显示密码」**
- 404 页整页英文：`Oops! Page Not Found!` / `Go Back` / `Back to Home`——**已汉化**
- 右下角 `TanStack Router` 徽标是**开发模式的 devtools**，打包后不出现，不属于 UI 缺陷
- 路由里还挂着 `sign-up`、`forgot-password`、`otp`、`sign-in-2` 四个上游 demo 页。
  本地工作台没有自助注册、没有邮件找回、没有短信验证码，其中 `otp` / `sign-in-2` 无任何入口。

### 2. token 层：stock shadcn slate，不是定制主题

`theme.css` 的色值就是 Tailwind slate 系（hue 264.695，蓝味明显），说明**主题从未被定制过**，
是 `shadcn init` 的默认产物。所以「品牌色」这件事目前不存在。

### 3. 遗留层：一套已经破碎的"石墨"

`features/local-workbench/local-workbench.css` 等 3 个文件里 50 处硬编码 hex
（`#242629` 近黑字 / `#f6f7f8` 灰底 / `#e1e3e6` 边框），卡片写死 `border-radius:12px`。

它与 token 层直接冲突：

| | 遗留层 | token 层 |
|---|---|---|
| 卡片圆角 | 12px | 10px |
| 字重 | 650 | 600 |
| 卡片底色 | `#fff` 硬编码 | `--card` |
| 页面底 | `#f6f7f8` | `--background`（白） |

另有 15 条规则挂在 `.local-workbench` 前缀下，而**全项目没有元素带这个 class**——死规则。
`WorkbenchShell` 上还留着 `graphite-workspace local-desktop` 两个作用域 class，代码注释自认
"have not been ported to Tailwind yet"。

### 结论

**当前没有可命名的风格。** 它是「shadcn 默认模板 + 一套未清干净的遗留石墨」的拼合体：
外层是模板的通用感，内层是半死的石墨灰，两者在圆角、字重、底色上打架。
README 写的「紧凑石墨黑白」只存在于遗留层，而遗留层已经漏了。

## 二、要改成什么风格：石墨紧凑（Graphite Dense）

### 为什么是这个方向

1. **README 已经声明过**「界面采用紧凑石墨黑白风格」——不是新方向，是把既定方向做完整。
2. **产品性质决定**：内部运营工具，用户一天盯 8 小时，看的是表格和状态，不是品牌。彩色和留白都是成本。
3. **改造成本最低**：31 个 shadcn 组件、侧边栏布局、CVA 变体全部可复用，只需换 token 值和清理遗留层，不用重写页面。
4. **单色在暗色模式下最容易做对**：多色强调在暗色里几乎必然出现对比度事故，单色没有这个问题。

### 目标规范

**色彩（单色阶，零彩色强调）**

| Token | 目标值 | 说明 |
|---|---|---|
| `--background` | `oklch(1 0 0)` 白 | 保持，不做灰底 |
| `--foreground` | `oklch(0.18 0.004 265)` ≈ `#1b1c1e` | 去蓝味，纯石墨黑 |
| `--primary` | `oklch(0.21 0.006 265)` ≈ `#1d1e21` | 主按钮近黑，chroma 从 0.042 降到 0.006 |
| `--muted` / `--secondary` | `oklch(0.968 0.002 265)` ≈ `#f4f4f5` | 中性灰，不带蓝 |
| `--muted-foreground` | `oklch(0.55 0.004 265)` ≈ `#77787c` | 说明文字 |
| `--border` | `oklch(0.92 0.002 265)` ≈ `#e4e4e7` | 唯一的分层手段 |
| 状态色 | 保留 `destructive` / `warning` / `attention` | 只有状态可以有色，且不用于装饰 |

**形态**

- 圆角：控件 8px、卡片 10px、徽标 pill。**删除 12px 和 5px**。
- 分层：只用 1px `--border`。阴影仅用于浮层（dropdown / dialog / sheet），页面骨架零阴影。
- 间距：4 的倍数；主区 `p-4 md:p-6`（现状已符合，保留）。

**排版**

- 字号：12 / 13 / 14 / 16 / 22 / 30 六档。**删除 11 / 15 / 17 / 24 / 25**。
- 字重：400 / 500 / 600。**删除 650**（现 3 处）；700 只给 404 那种大数字。
- 行高：正文 1.6，表格 1.5，标题 1.4。
- 中文标题**不加负字距**（现 `-.04em` 用在中文 h1 上，会把汉字挤扁）。

**密度**

- 表格行高 40px，单元格 `10px 16px`，表头 `bg-muted`。
- 侧边栏 + 顶栏 56px（现状已符合，保留）。
- 页面标题 22/600，紧跟一行 13px 说明，不加大段副标题。

**结构清理**

- **`forgot-password` 必须处理**：它没有任何后端调用——`forgot-password-form.tsx` 用 `sleep(2000)` 假装发信，
  然后弹「Email sent to …」并跳到 `/otp`（同样是空壳页）。而工作区里有一处**未提交改动**
  刚在登录页加了「忘记密码？」入口指向它。等于给用户开了一条假流程，比死链更糟。
  二选一：补真实重置能力，或删掉入口和这两个页面。
- 删除 `sign-up`、`otp`、`sign-in-2` 三个上游 demo 页——本地工作台没有自助注册和验证码流程。
- 补全中文：`Show password` → `显示密码`；404 页整页汉化。**（已完成）**
- 去掉 `<title>` 的 `- TanStack Router` 后缀。**（不存在此项：那是 devtools 徽标，不是标题）**

### 与现状的差异清单

| 项 | 现在 | 目标 |
|---|---|---|
| 主色 | `#0f172b`（蓝味 slate） | `#1d1e21`（中性石墨） |
| 卡片圆角 | 10px / 12px 并存 | 统一 10px |
| 字重 | 600 / 650 并存 | 只用 600 |
| 字号档位 | 12 种 | 6 档 |
| 页面底 | token 白 与 `#f6f7f8` 并存 | 只有白 |
| 彩色 | 遗留层有绿/砖红 hex | 仅状态色 |
| 英文残留 | 4 处 | 0 |

## 三、施工顺序（每步可独立验收）

1. **清死代码**：删 15 条 `.local-workbench` 死规则、`graphite-workspace` / `local-desktop` 作用域、4 个 demo 路由。
   纯删除，不改观感，`npm run ui:check` 错误应减半。
2. **收 token**：把剩余 hex 换成语义变量，补 `--warning` / `--attention`（已加）。此步观感应几乎不变。
3. **换色阶**：改 `theme.css` 的 `:root` / `.dark` 为石墨值。此步观感明显变化，需要逐页截图核对。
4. **压档位**：删 11/15/17/24/25 字号、650 字重、12px 圆角，逐个改成最近档位。此步要配合截图看有没有挤在一起。

第 3 步之后才谈得上「换风格」，前两步只是把地基清平。

## 四、备选方向（如果不想走单色）

- **B｜冷灰蓝 + 单一强调色**（Linear / Vercel 路线）：保留 slate，只把一个强调色（比如靛蓝）用于主操作和选中态。
  比单色更有辨识度，但暗色模式下需要额外校对比度。
- **C｜回到雾白 + 海松绿**：`docs/UI-CONSISTENCY-AUDIT-2026-10-26.md` 记录过的那套（`#F6F8FB` / `#12856F`）。
  **不建议**——代码里已 0 处残留，等于从头再来一遍，且那份审计的 31 张截图已不对应当前实现。

推荐 A（石墨紧凑）。它不需要新增设计资产，且与 README 声明一致。
