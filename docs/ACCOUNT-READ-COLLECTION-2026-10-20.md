# 批准账号的单次只读采集联测

> Windows续做状态以[Windows适配与待验收](WINDOWS-ADAPTER-2026-10-20.md)为准；本历史记录中的Windows未实现描述保留当时事实。

当前交付包含实现和离线验收。**尚未批准生产设备、真实扫码或读取真实平台；不能据此宣称真实链路已通过。** 不回退设备与登录模块，不读取、迁移或删除旧 Cookie，不操作原临时工作台。

## 用户下一步

在已有项目目录运行：

```sh
npm run dev:persistent
```

启动器复用该实例自己的持久卷与管理员，应用迁移 `202610200009_account_read_execution`，启动 API、前端及专用采集 worker。没有自动平台调用；已有旧版本实例若仍运行，需要用户在原终端正常结束后再启动，不能并行占用同一实例。本次没有重启用户实例。初次没有管理员时沿用交互初始化。

1. 打开终端输出的 loopback 地址，进入账号中心，以管理员审阅执行设备与私有凭证目录，明确批准。批准前不会生成生产设备认证私钥。
2. 添加小红书账号，确认本地会话保存用途，生成二维码并由本人扫码。只有接口明确返回已登录及稳定平台用户 ID 才能绑定。缺少 ID 会进入待核查，不能用昵称代替。若已有批准的会话，本次重启后需勾选并主动核验；不会扫描导入旧会话。
3. 在搜索设置创建配置：模式选 **小红书只读**，首轮关键词 **无偿选题**，帖子上限 **3**。关键词仍可配置；本入口所有非模拟账号读取最多3篇。
4. 在采集任务选择这份配置及已核验的账号，核对实际执行设备，勾选“仅执行当前配置的一轮只读采集”，再开始。本次授权只对应这一轮，完成后勾选清空。每次再次运行都须明确确认。
5. 查看运行记录、匹配评论及来源。有限窗口正常结束显示“部分完成”；零命中不代表失败，也不能证明没有需求。向协作任务确认扫码完成和本轮结果后，才能继续记录真实联测结论。

这轮仅搜索并读取可获得的公开帖子/评论窗口，再做规则筛选和稳定 ID 去重。公开评论可能有需求，**并不代表同意营销**；人工审核与勿联系状态保留。评论、私信、点赞、删除会话等写操作不在只读调用白名单中。无定时采集、自动重试或换号重试。遇到限流、验证码、封禁等停止并保留失败原因，由人工核查，不绕过限制。

## 账号、设备与权限边界

- 保留全局 `XHS_MCP_ENABLED=0`，不连接统一的旧 MCP 端点。持久入口内部启用 `CRM_ACCOUNT_READ_ENABLED=1`，真实模式使用账号绑定路径，离线模式只使用明确标注的虚构协议驱动。不要手工设置旧的全局 MCP 环境变量。
- HTTP 仅管理员可配置、启动、暂停；沿用会话、Origin、CSRF 校验。运行快照固定操作者、账号、稳定 ID、版本、会话引用、设备 ID、密钥代际和本次工作台运行期；队列只传内部 runId，不传凭据或任意命令。
- 执行前校验操作者仍有效、账号未归档/人工暂停/受限、引用已在本运行期验证，设备签名通过且凭证目录仍安全。扫码、保存会话核验、采集共用按账号唯一租约；同账号并发不能双开浏览器。
- 本次账号执行启动自己的已审阅 MCP 子进程，固定本机 loopback 端口、随机内存 Bearer 令牌、准确账号会话目录。沿用已审阅二进制哈希和浏览器版本，不安装新程序、不读取普通浏览器 Cookie。登录状态接口返回的稳定 ID 必须与绑定 ID 完全一致，才准进入搜索。
- 任务进行中检查本地取消、权限、账号版本、设备撤销与租约；提交前在数据库锁中再检查，防止迟到写入。新工作台运行期不能消费旧授权，旧任务需明确重新提交。设备名或 UUID 本身不是认证。
- 默认登录后的“暂停”表示联系/发送暂停，单次只读授权是独立用途。管理员随后设置的其他暂停原因、归档或账号版本变化阻止采集。限流、受限、登录失效或稳定 ID 不匹配将账号标记受限、会话待核查、配置暂停；不会自动恢复或换号。
- 尚无独立远程 Agent/Windows 支持；继续采用 Mac ARM64、本地 APFS 和当前 API 同机执行边界。

## 有限读取、数据与失败语义

最多3篇、32次适配器读取、100条评论；单次平台调用40秒，采集阶段150秒，包含预检的执行进程总期限160秒。界面只轮询本地任务状态，最多3分钟，不会因此重复请求平台。取消/超时会中止本次自有平台进程；没有后台持续采集。

复用 `XhsMcpAdapter`：只允许 `check_login_status`、`search_feeds`、`get_feed_detail`。详情固定 `load_all_comments=false` 和 `click_more_replies=false`，上游没有经过验证的游标续读接口；嵌套回复只处理返回窗口，不能宣称全量。返回字段、大小和 ID 均校验；缺失稳定用户 ID 的响应拒绝入库，不猜同一人。

外部响应是非可信数据，不会成为指令，不动态扩展工具白名单，不执行评论内容，也不调用外部模型或发送到其他第三方。只保留必要公开稳定 ID、帖子标题、命中评论原文/昵称、父评论引用与来源/覆盖元数据；未命中评论只保留去重观察所需 ID。不持久化 xsecToken、MCP Bearer、Cookie、二维码或私钥到业务表、审计或截图。

线索按平台+平台用户 ID 合并，评论按平台+评论 ID 去重；昵称不是身份键。现有首次联系全局去重、人工审核和勿联系机制不变，采集不授予联系权限。真实模式 `isDemo=false`，离线夹具采用 `fixture-xhs-` 前缀及 `isDemo=true`。真实异常绝不回退 mock；失败时不提交本轮来源，保留以前成功记录。预算达到时可部分入库，但明确显示覆盖不全。
