# Qwen 评论语义匹配：配置、控制与边界

仅评论匹配，不生成回复、不发送评论或私信。独立 LLM 开关默认关闭。保存目标、开启队列或恢复服务不会发起模型请求。原教培配置不自动改写。

## 使用路径

工作台 → 自然语言审核 · 手动评估 → 原文存档。

1. 先在搜索设置编辑自然语言目标。帖子搜索词、旧关键词规则、自然语言目标和 LLM 运行开关相互独立。旧表单“启用自然语言审核”表示保存目标，实际运行由独立开关控制。
2. 关闭 LLM 时，主动采集只增量保存实际读取到的帖子、一级评论、回复及父评论上下文；语义状态为未分析，评分为空。旧关键词命中视图继续兼容，但不会删除未命中原文。
3. 开启独立 LLM 开关后，新增原文进入待分析队列。也可选择已保存评论（每次最多5条），预览脱敏文本、加入当前目标/型号的分析队列，无需重采。
4. 下方“预览所选批次”展示真正待请求的文本。模型、价格确认、预算和独立开关都就绪，且人工逐项确认后，才允许一次模型请求。默认下一批也最多5条。自动脱敏不能可靠识别所有自然语言姓名/身份，因此目前自动入队，不无人审核自动付费。
5. 已完成的相同目标/型号/上下文版本/内容哈希复用结果。修改目标或型号后保留新旧结果与引用。失败/超时不是低分；仍待审核。未知网络结果可能已收费，只有重新预览并明确确认后才可人工重试，不能保证服务商不计费。
6. 关闭开关阻止新的模型请求；已经发出的请求不能撤回，可能完成并保留结果。真实发送始终关闭，评分与审核都不能授予发送资格。

历史仅有 ID 的观察记录不具备原文，页面显示缺口数量，不伪造或自动重新采集。原文与版本列表分开计数。采集中断后已提交的增量快照保留；覆盖仍为部分或未知，不能据此推断不存在其他评论。

## 桌面配置入口（不要发送 Key 到聊天）

首次引导完成后，打开「配置管理 → 模型」。无需工作台登录；引导本身不配置 Key 或发起付费请求。

1. 用户自行输入 Key 并加密保存，由 Electron 系统凭据保护保存在本机。页面只显示配置状态。
2. 选择受控型号、每日请求次数，确认价格版本与评论原文发送范围后保存审核授权。
3. 对需要的匹配目标显式允许审核；整轮自动审核还需独立的持续付费调用授权。
4. 替换 Key 会撤销既有模型、目标及自动联系授权，需要重新确认，不沿用旧服务账号的授权。
5. 保存成功不等于 Key 有效或服务可用，也不触发模型测试、平台采集或消息发送。

当前接口提供 Key 保存/替换；旧管理员 HTTP 页面、独立主密钥初始化和删除表单不属于桌面功能。
跨电脑需要重新输入 Key，不通过复制旧主密钥或旧环境变量自动恢复。具体边界见 [桌面模型凭据说明](model-settings-security.md)。

## 隐私、预算和故障

外发只包含目标、帖子/评论/必要父评论和缺失/部分/截断标志。去除身份元数据、原ID、URL及文本中的联系方式；可疑残留信息阻断整批。人工必须逐项确认不含姓名、昵称、身份、链接或联系方式；无法判断则取消。原文和来源快照只留本地。

全局并发1。评论审核按每帖 50 条评论分批、一批一个请求，单批最多 3 次尝试（首次 + 2 次重试），重试间隔 30 秒（429 为 60 秒），整批请求超时 300 秒，每日 1–100 次；可重试错误、耗尽暂停与结果未知处理见 [review-batching.md](review-batching.md)。事务预留预算、请求键幂等、行版本及预览哈希防止双击或并发重复调用。预留/失败/中断占次数；记录已知token与用量未知。失败保留已审结果、未审评论不标记为已审。过期租约不会自动重放。评论/帖子是非可信数据，没有工具或发送能力。
