## 推荐方向

A（推荐）：Attio 浅色 CRM 信息组织 + Linear 式克制细节。适合当前线索、原文依据、负责人、跟进、任务这些高频桌面操作。浅灰侧栏与白色工作区，青绿作为少量强调色；统计区压缩，列表为视觉主体；详情分层展示。

B：Linear 深石墨工作台。视觉差异最大，适合偏好深色者；中文小字、状态对比和长时间阅读须专门校验。

C：Twenty 极简白色工作台。熟悉、轻巧、信息密度高；风格更安静，动效存在感更低。

拟议动效：按钮/状态反馈约 120–160ms，筛选和页签切换约 160–200ms，详情抽屉约 220–280ms。数值是本项目建议，不是对参考产品的测量。保留列表位置，避免打开详情重播整页/表格入场，支持减少动态效果。

获准修改后仍保留演示/真实连接区别、账号受限状态、原文证据与人工确认；风格改造不增加未经验证的平台能力。
