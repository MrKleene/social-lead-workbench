## 状态词

沿用 [MODULES.md](MODULES.md) 的证据等级，不另造同义词：

| 词 | 含义 |
| --- | --- |
| 已接入 | 代码在主路径上，可被实际调用 |
| 合成验证 | 有隔离测试（mock / fixture / 本地库），**未碰真实平台** |
| 真实未验收 | 需要真账号、真平台、真付费，当前没有证据 |
| 仅预览 | 只能本地读数据生成结果，不能发 |
| 未交付 | 代码或安装包没到可用状态 |
| 不适用 | 纯本地能力，不依赖真实平台 |

**"已接入 + 合成验证"不等于可用。** 离线测试全绿只能证明代码按契约工作，不能证明平台、模型、发送或接收在真实环境成立。

## 分发形态与已知限制

- 分发：GitHub Releases 直接下载，官网只做落地页；不依赖应用商店。
- 许可：计划 source-available（PolyForm Noncommercial 1.0.0），允许个人本机使用、禁止商用；不是 OSI 开源许可。`integrations/inbox-mcp` 为 Apache-2.0 衍生，公开前补 NOTICE。
- macOS：未签名、未公证，首次打开需右键打开或移除隔离属性；其他机器安装、升级与 Intel Mac 未测；公证需付费 Apple Developer 账号。
- Windows：安装包未构建，SmartScreen 会提示；企业环境可能被策略拦截。
- 版本：当前为测试阶段，尚无对外版本号。

## 已移除或不在范围

- 旧工作台账号密码体系（注册、验证码、找回密码、退出登录）与旧 HTTP 服务，不恢复。
- 旧库迁移、离线导入与只读导出：没有旧工作台数据，不进入公开发布范围；代码保留，但不作为发布门禁。
- 与旧工作台的功能对等：不作为验收目标，本产品独立演进。
- 历史采集、审核、收件记录只保留只读归档，不提供旧业务写入入口，也不物理删除历史证据。
- 用户离开平台后的站外转化不属于产品范围。
