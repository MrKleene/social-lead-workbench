## 状态词

沿用 [MODULES.md](MODULES.md) 的证据等级，不另造同义词：

| 词 | 含义 |
| --- | --- |
| 已接入 | 代码在主路径上，可被实际调用 |
| 合成验证 | 有隔离测试（mock / fixture / 本地库），**未碰真实平台** |
| 真实未验收 | 需要真账号、真平台、真付费，当前没有证据 |
| 仅预览 | 只能本地读数据生成结果，不能发 |
| 未交付 | 代码或安装包没到可用状态 |
| 不适用 | 纯本地能力，不依赖真实平台 |

**"已接入 + 合成验证"不等于可用。** 离线测试全绿只能证明代码按契约工作，不能证明平台、模型、发送或接收在真实环境成立。

## 阻断正式发布的未完成项

1. 私信真实发送：缺可验证的 API/工具契约、真实会话绑定、收件人校验、额度原子预留、单次派发与 UNKNOWN、DM 专属队列与回执映射。
2. Windows 11 真机与安装包：原生编译/运行、系统凭据、干净机器安装/升级/卸载均未实测。
3. macOS 签名与分发：Developer ID 签名、公证、Gatekeeper、其他机器安装升级未完成。
4. 真实平台链路：真实评论发送、自然新消息时效、平台登录与采集实际覆盖仍未验收；付费审核与采集只有 2026-11-18 单轮 3 帖证据，长期多轮稳定性未验证。
5. 与旧工作台的功能对等：不能认为原产品功能已全部迁完；一次测试通过不等于对等。

机器门禁：`npm run desktop:release-check` 输出
`Desktop release is blocked. Do not replace the production instance.`，
任何一项未验收都不应替换生产实例。

## 已移除或不在范围

- 旧工作台账号密码体系（注册、验证码、找回密码、退出登录）与旧 HTTP 服务，不恢复。
- 历史采集、审核、收件记录只保留只读归档，不提供旧业务写入入口，也不物理删除历史证据。
- 用户离开平台后的站外转化不属于产品范围。

## 维护规则

1. 实现或验收变化时：先更新 [IMPLEMENTATION-STATUS.md](IMPLEMENTATION-STATUS.md) 与
   [ACCEPTANCE.md](ACCEPTANCE.md)（必要时含 `release-readiness.json`），再同步本表。
2. 没有真实回执证据的能力不得写成"验证通过"，只能写"真实未验收"或"仅预览"。
3. 状态词与 [MODULES.md](MODULES.md) 保持一致；新增能力先在 [REQUIREMENTS.md](REQUIREMENTS.md) 加范围，再加本表行。
