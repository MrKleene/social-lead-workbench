# 采集、评论匹配与自动回复

主流程为采集 → LLM 评论匹配 → 自动回复。侧栏入口为「获客数据采集」与「待处理发送」；采集页与「采集与审核设置」只包含采集、评论匹配两步。自动入队在「配置管理 → 自动加入待发送队列配置」按匹配方案设置阈值与渠道；自动发送的账号池、模板池、渠道开关和额度刷新时间在「配置管理 → 自动发送配置」，总开关在「待处理发送」页头。审核结果达到对应方案的入队阈值后进入「待处理发送」队列；发送处理结束后不等待入站回复，入站回复监控仍未接通。

任务状态由只读 `/auto-contact/journey` 汇总完整 run 的审核和规则任务，不使用最近 20 条或当前全局开关冒充历史进度。未知发送、待处理、审核失败、取消/跳过审核与未知状态均不会标为全部完成；模拟结果明确标注。

「采集与审核设置」弹窗按两步展示：

- 采集：现有关键词组、平台、模式、默认采集账号、单轮帖子上限及本轮范围。每次手动一轮；真实采集当前最多 3 帖。每轮开始时随机打乱关键词顺序并固定平台筛选（最多点赞、一周内），执行时按种子确定每个关键词 1~剩余篇数的配额，词间停顿 3~8 秒；每个关键词只读搜索第一页。选帖时跳过历史上已完整采集的笔记，未读全的仍可重采。计划内关键词按序搜完仍不足设置篇数时标为「结果不足」，不追加关键词。评论采集有既有服务端有限窗口，不宣称读尽全平台；完成判定以页面结构自洽为准，平台全局评论计数只作为「平台声明 N 条，已读取 M 条」证据；确认空评论的帖子按完整处理。每帖兜底 60 秒 + 平台声明评论数 × 1.2 秒（90 秒~40 分钟），整轮按各帖预算之和加 5 分钟余量、硬顶 150 分钟，连续读取每满 10 分钟停顿 20~40 秒；命中时限保留已读并标「达到单帖/整轮时间上限」。平台限流时保留已读并停止本轮。队列里还有运行中或待执行的采集、审核、回复任务时，不允许开始新一轮采集；点「开始采集」后先显示「正在启动」，本轮任务落库后再展示进度。
- 评论匹配：需求描述、已保存目标选择、自动匹配开关及原有付费调用授权。复用全局模型；按原顺序每 50 条评论一批调用，单批最多 3 次尝试（首次 + 2 次重试），仅网络连接失败、429/5xx 与模型返回格式异常自动重试，间隔 30 秒（429 为 60 秒）；单段耗尽暂停该帖、连续 3 段耗尽暂停整轮，结果未知立即暂停全部模型调用且不自动重试；鉴权、容量/价格、配置变化不自动重试。只审核已完整读取的笔记；未完成帖在采集结果中标「待补读」，补读后再审，同一评论在同一规则修订下不重复计费。完成判定为该帖全部可送审评论（正文非空且不超过 200 字符）都有同一规则修订和内容哈希下的审核结果；正文为空或超过 200 字符的评论不送审、不计入进度，超过 200 字符的评论在界面上单独显示为「跳过（评论超长）」，证据引用非空白字符须逐字一致、空白按等价处理。审核理由为中文；失败原因在任务页按网络/限流/服务异常/格式/鉴权/容量/结果未知展示。详见 design/review-batching.md。
自动加入待发送队列配置位于「配置管理 → 自动加入待发送队列配置」：每条匹配方案单独设置分数阈值、入队渠道（评论 / 私信）与是否启用；系统默认评论匹配规则预置 80 分、双渠道，可编辑不可删除。审核完成时按该评论所属方案判断，只有 `MATCH` 且分数达到阈值才为每个勾选渠道各生成一行；没有配置或已停用的方案不自动入队。人工「通过」把待确认评论写成 `APPROVED + MATCH` 并入队，不受阈值限制；`NO_MATCH` 不显示通过。自动发送总开关或渠道开关关闭时仍入队等待。

自动发送配置位于「配置管理 → 自动发送配置」：现有发送账号池、评论 / 私信模板池、额度刷新时间（默认 00:00）与评论 / 私信渠道开关；阈值不在这里。开启总开关前至少选一个渠道，且每个勾选渠道都要有模板和账号。评论与私信同一收件人各自独立首联，跨渠道去重。手动「立即发送」一次只接受同一渠道，并覆盖账号与模板。

待处理发送页分为待发送 / 等待额度 / 发送失败 / 结果未知 / 已过期五类。评论审核页头「生成待发送」按全部历史审核各自的匹配方案补齐缺失队列，不受当前筛选影响；先预览可入队评论数、评论 / 私信行数、过期与跳过数，确认后写入；重复执行幂等。待发送与等待额度可「移出待发送」，发送中不可移出；失败可重试，失败 / 未知 / 过期可「移除记录」；过期可重新排队，评论发布超过 7 天需显式覆盖。入队超过 7 天或评论发布超过 7 天的条目进入已过期，过期记录 30 天后清理。

采集与审核设置、自动加入待发送队列配置与自动发送配置分别保存，没有跨接口原子提交或“全部保存成功”提示。切换页签保留草稿，关闭需确认丢弃；保存失败保留该组草稿并显示错误。启动采集只校验采集与评论匹配的必要条件，不再读取或冻结回复规则；自动入队或自动发送配置缺失不会阻断采集。读取失败会阻止误判开关关闭。

回归范围：完整项目单元/HTTP 测试、类型与构建；隔离浏览器的合成保存/部分失败、条件校验、授权不自动开启、桌面/390px、草稿取消、刷新、历史任务、前后退、嵌套选择、遮罩与 Dock。生产只读验收，不运行真实采集、模型或发送，不变更业务开关或账号状态。
