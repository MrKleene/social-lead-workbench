# 采集信息：帖子优先浏览 · 2026-10-22

关联 REQ-002/007/031/033；基线 151a741。仅前端与隔离测试改动，原后端、数据库、密钥、启动器未改，没有服务停启或真实采集/模型/发送。

## 使用

打开 `/work?module=archive`，或首页「采集信息」卫星入口、顶部导航、Dock、全局菜单。原「采集结果」名称统一为「采集信息」，采集任务结束后的按钮也进入同一模块，保留旧深链。

默认展示帖子卡片。选择帖子即可阅读该帖本页评论、回复缩进、父评论原文及来源 ID；独立帖子正文按需展开。未获取标题、正文或父评论不补猜。仅有旧观察 ID 的记录明确提示缺失原文。LLM 关闭或没有评分、没有转线索均不影响原文阅读；原语义分析入口保留在次级折叠区域。

关键词组、搜索与任务筛选复用已有数据。配置、选中帖子、评论页、搜索词及任务筛选写入本地页面 URL；刷新仍可定位。返回帖子列表保留筛选、页码、滚动与卡片键盘焦点；模块切换复用既有历史。URL 只用于页面定位，不创建业务数据。

## 接口边界

现有 GET `/collection/configs/:id/captures?offset=…` 返回配置内每页最多 50 个评论上下文版本，以及最近 20 个帖子版本。没有独立帖子分页、每帖评论总数或帖子专用评论分页接口。本轮不修改后端。

因此列表来自最近 20 个帖子版本和本页评论关联的帖子；按平台帖子 ID 合并，原文版本仍保留。卡片的「本页已采集 N 条评论／回复」按本页独立评论 ID 计数，既不是配置内该帖完整已存数量，也不是平台总评论数。下一页仅翻评论，已选择帖子保持，可能出现该页无对应评论；不会误报平台无评论。页面范围行明确说明当前窗口，完整解释放在「保存范围与分析」。旧任务归属仍只有首次/最近观察，不能还原中间每轮完整快照。

来源仅展示接口实际提供的平台、帖子/评论 ID、观察时间及原文，不构造未经验证的外部链接。评论顺序沿用接口，缩进依据实际父 ID，缺父原文明确提示；不同上下文版本不误删。
