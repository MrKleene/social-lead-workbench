# 原工作台 → 本地桌面逐页核对

核对依据为隔离副本中的原 `apps/web/src/main.tsx`、`components/app-navigation/navigation-model.ts` 及各 feature 的实际页面/表单/请求代码；原项目只读，基线单独复核。不是按旧报告或截图猜测功能。本轮删除单页 `local-workbench.tsx` 入口，桌面使用本地 hash 路由、原导航模型与 graphite 样式；调用受限 IPC，不回连旧 HTTP 服务。

## 完整性与安全

本轮整轮审核是新授权，不是恢复旧任务：冻结“尚未提交”的精确批次列表及原文摘要，预览总请求/输入数和费用估算，再原子创建任务。既有成功、失败、未知批次一律不自动重试；间隔、每日额度、授权十五分钟、取消、模型暂停和重启保护都保留。范围过大时要求单批处理，不放宽 IPC 大小限制。批次实际发生未知后后续任务不调用模型，授权过期则取消。

账号池只在首次分配且未产生 attempt 前选择下一有额度账号；账号身份/风险异常立即停止该项规划，不能作为失败换号路径。已分配任务不会迁给另一账号。额度统计包括尚未预留 attempt 的活动待发任务，提交时原共享额度检查仍执行。

页面仍然有以上明确差异，因此不能宣称与原工作台全部逐项等价。主要业务入口已从长单页迁回实际工作台结构，使用的是本地真实业务仓储与原平台协议；合成测试只是隔离验收方式，没有替换正常运行时适配器。

## Windows 和 Mac

Windows 增加 `scripts/desktop/windows-preview.ps1`：绝对构建输入和浏览器 SHA 核对 → 原生验证 → NSIS → 最终包源码/资源/安全开关核验 → 包内离线自检。`verify-package.cjs` 现在能在原生 Windows 上核对打包后的 helper、浏览器、MCP、许可证和验证文件，而非固定写未验证。没有 Windows 11 x64 真机，本轮不能运行这条链或生成通过门槛的 Windows 安装包。

Mac 逐页实际 Electron 合成测试包含导航、五类配置、未保存草稿、排除词、原任务步骤组件、整轮审核预览、账号额度编辑、原回复表格/详情、评论通知与私信筛选/未读、导入/重启及窄屏。最终结果与安装包信息见 `.local/desktop-qa`，版本信息以产物清单为准。真实平台、付费模型、签名/公证与干净机器升级仍未验收。

## preview.6 验证补充

新增按组自动保存、旧偏好读取及备份恢复后授权仍关闭、未评分/失败筛选、发布时间保留、本地资格诊断、模型与规则统计、原诊断组件。源码沿用 SQLite v9 的版本化 settings，无新数据库迁移。设置写入使用版本比较，保存本身不生成任务或授权；切换组不会自动换用其他账号。Windows 构建增加原生 x64 主机检查、固定版本安装包名和成功后才写出的哈希/签名状态清单；本机未生成 Windows 验收记录。
