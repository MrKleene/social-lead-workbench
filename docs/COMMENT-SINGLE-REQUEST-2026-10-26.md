## 容量与费用

官方资料核对了 [Qwen3.8-Flash](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[Qwen3.8-Max 及快照别名](https://help.aliyun.com/zh/model-studio/qwen3-8-max)、[Qwen3.7-Flash](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)、[Qwen3.7-Plus](https://help.aliyun.com/zh/model-studio/qwen3-7-plus)：非思考最大输入 991808、最大输出 131072、上下文 1000000 tokens。既有型号及价格确认不变，无自动切模型。

这不是无限容量承诺：用请求 UTF-8 字节数加协议余量作保守输入 token 上界，并为每条完整结果预留输出空间。整帖结构要求简洁理由最多 120 字符、1 条最多 120 字符的逐字 COMMENT 证据；评论输入本身不截断。输出额度随完整评论范围计算，不再固定 2500 tokens。超出输入、输出或总上下文预算时在预览确认前阻止整帖，不拆分或仅处理前几条。估算不是提供方 tokenizer，可能保守拒绝实际能容纳的较大帖子。

[官方结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)支持本次使用的 maxLength/minItems/maxItems。该文档建议不设 max_tokens 以避免 JSON 截断；本项目为约束一次费用保留显式输出额度，并按完整紧凑 schema 的保守空间计算，拒绝非 stop、缺条数或非法引用，不把截断结果当成功。单次超时 5 分钟，数据库保留期 6 分钟、中断检查 7 分钟，避免仍在请求时启动新的付费尝试；响应体有界。实际 tokens 与费用以提供方账单为准。
